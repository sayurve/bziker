# Передача проекта «Бзикер»

Репозиторий: [sayurve/bziker](https://github.com/sayurve/bziker), **public**. Получатель может просматривать и скачивать проект по ссылке без приглашения. Право изменять репозиторий автоматически не предоставляется.

Проверенный исходный снимок v25: `4b1c2e97c4182a2be6acc1f900da5ee9152faaad`. Код, графика, документы, тесты и сохранённые иллюстрации проверок находятся в этом репозитории.

## Получение и локальный запуск

Для запуска требуется Python 3.10+. Для получения исходников нужен Git, для клиентских тестов — Node.js 22+.

Для скачивания исходников из открытого репозитория авторизация не требуется. Можно использовать команду ниже или кнопку **Code → Download ZIP** на GitHub.

```sh
git clone https://github.com/sayurve/bziker.git
cd bziker
AUTH_MODE=demo HOST=127.0.0.1 python3 server.py --port 8791 --db data/game.db
```

Открыть `http://127.0.0.1:8791/`. Сервер создаст новую SQLite-БД. Рабочую БД с существующим прогрессом оператор передаёт отдельно; она исключена из GitHub и архива.

## Проверки

```sh
npm ci --ignore-scripts
python3 scripts/check-handoff.py
python3 -m unittest discover -s tests -v
npm test
```

До передачи проверенный снимок прошёл 710 JavaScript-тестов, 322 Python-теста и проверку 119 ресурсов. Проверка миграции сохранила 33 таблицы и 173 строки постоянных данных. Текущие результаты облачных проверок доступны в [GitHub Actions](https://github.com/sayurve/bziker/actions).

Подробные результаты исправлений v25 и снимки игры: [docs/bugfix-v25/verification.md](docs/bugfix-v25/verification.md). Состав проверенного пакета: [handoff-manifest.json](handoff-manifest.json). Результаты проверки переносимости: [HANDOFF-VERIFICATION.json](HANDOFF-VERIFICATION.json).

## Публичное размещение

Поддерживаемый публичный режим требует `AUTH_MODE=telegram`, Telegram-бота и `BOT_TOKEN`, корневого HTTPS-адреса `PUBLIC_URL`, TLS-прокси и постоянного каталога SQLite. Запускается один процесс сервера с одной БД. Режим `demo` разрешён только локально; `AUTH_MODE=account` отсутствует.

`.env` автоматически не загружается. Переменные передаются через окружение или службу запуска; токены и БД не добавляются в репозиторий. Порядок размещения описан в [DEPLOYMENT.md](DEPLOYMENT.md); шаблоны находятся в [deploy/](deploy/). Публикация репозитория сама по себе не размещает игру на сервере.
